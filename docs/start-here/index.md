# Start Here

This is an engineering knowledge hub for people building machines that perceive, learn, reason, plan, and act in the physical world. Explore a topic when you need it, or follow the [suggested learning path](learning-path.md).

## Choose your starting point

- **New to robotics:** Start with [programming and systems](../foundations/programming-and-systems.md), [mathematics](../foundations/mathematics.md), and [mechanics and electronics](../deployment/mechanics-and-electronics.md).
- **Comfortable with software or ML:** Explore [kinematics](../simulation/kinematics-and-dynamics.md) and [physics simulation](../simulation/physics.md) before training robot policies.
- **Experienced with robotics:** Explore [imitation learning](../robot-learning/imitation-learning.md), [world models](../robot-learning/world-models.md), and [experience data](../robot-learning/experience-data.md).
- **Ready to build:** Use the [SO-101 project brief](../projects/so101.md) to plan a reproducible experiment.

## How to use a topic guide

Each guide introduces the topic, links prerequisites, identifies key concepts, suggests a small experiment, and points to documentation and next steps. These are growing study notes and experiment outlines; linked documentation provides tool-specific instructions.

## Working principles

- Learn by building and measuring.
- Account for the robot's body, sensors, and environment.
- Treat simulation as a model that needs validation.
- Record data, configuration, software versions, and results.
- Constrain and supervise hardware experiments; simulation success does not establish hardware safety.
