# Suggested Learning Path

Choose a project, identify what you need, and iterate between learning, simulation, and deployment. This is a flexible reading path, with no enrollment, assessments, or fixed schedule.

Start hardware and ROS 2 exploration early if suitable equipment is available. You can also begin entirely in simulation.

## 1. Build a foundation

- [Mathematics for Physical AI](../foundations/mathematics.md)
- [Deep Learning with PyTorch](../foundations/pytorch/index.md)

**Experiment milestone:** A repeatable training run with an evaluation baseline.
