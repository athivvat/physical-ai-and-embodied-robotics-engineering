# Mathematics for Physical AI

## Overview

Mathematical tools for learning, spatial reasoning, and motion.

This topic guide identifies concepts to explore and an experiment to try. Use the linked documentation for implementation details.

## Prerequisites

Basic programming familiarity and an interest in physical systems. Start with the [learning path](../start-here/learning-path.md) for context.

## Key concepts

- Linear algebra (vectors, matrices, eigendecomposition, SVD).
- calculus and chain rule.
- probability and estimation.
- gradient-based optimization.
- 3D coordinate frames, rotations, quaternions and SE(3).

## Try it

Compute gradients and transformations; explain optimization updates; express rigid-body poses across reference frames.

Record your setup, inputs, measurements, and failure cases. Keep the experiment small enough to repeat, and compare the result against a simple baseline.
