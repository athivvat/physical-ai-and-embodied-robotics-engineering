# ML Systems, Data & Reproducibility

## Overview

Engineering practices for trustworthy, traceable model development.

This topic guide identifies concepts to explore and an experiment to try. Use the linked documentation for implementation details.

## Prerequisites

[Deep Learning with PyTorch](pytorch/index.md)

## Key concepts

- Dataset/model versioning.
- experiment tracking.
- data leakage and splits.
- evaluation metrics.
- model registries.
- training pipelines.
- deployment monitoring and data drift.

## Try it

Reproduce an experiment from versioned inputs; compare model versions; create a concise model/data evaluation report.

Record your setup, inputs, measurements, and failure cases. Keep the experiment small enough to repeat, and compare the result against a simple baseline.
