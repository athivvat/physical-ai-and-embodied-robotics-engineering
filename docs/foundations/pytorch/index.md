# Deep Learning with PyTorch

## Overview

Implement practical training pipelines and evaluate neural networks.

This topic guide identifies concepts to explore and an experiment to try. Use the linked documentation for implementation details.

## Prerequisites

[Mathematics for Physical AI](../mathematics.md)

## Key concepts

- Tensors, broadcasting, autograd.
- MLP/CNN and activations.
- losses, optimizers, regularization.
- Dataset/DataLoader.
- training/evaluation loops.
- checkpoints, mixed precision, profiling.

## Try it

Train and evaluate a model without a high-level trainer; debug shapes and gradients; profile and reproduce a training run.

Record your setup, inputs, measurements, and failure cases. Keep the experiment small enough to repeat, and compare the result against a simple baseline.
