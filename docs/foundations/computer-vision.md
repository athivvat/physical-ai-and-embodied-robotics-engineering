# Computer Vision & Visual Perception

## Overview

Extract object, geometry, and scene information from cameras and other sensors.

This topic guide identifies concepts to explore and an experiment to try. Use the linked documentation for implementation details.

## Prerequisites

[Deep Learning with PyTorch](pytorch/index.md)

## Key concepts

- Image processing.
- pinhole cameras and calibration.
- classification/detection/segmentation.
- depth and point clouds.
- pose estimation and tracking.
- visual representations and uncertainty.

## Try it

Build a calibrated perception pipeline; estimate relevant object properties; quantify perception errors affecting robot actions.

Record your setup, inputs, measurements, and failure cases. Keep the experiment small enough to repeat, and compare the result against a simple baseline.
