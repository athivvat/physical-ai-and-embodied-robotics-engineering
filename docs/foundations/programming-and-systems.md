# Programming & Systems

Build small, observable programs before integrating a complete robot.

## Key concepts

- Python for data processing, experiments, and model training.
- C++ for performance-sensitive control and robotics software.
- Linux, shell tools, processes, permissions, and device access.
- Git, automated checks, dependency management, and reproducible environments.
- Data structures, graph search, and timing constraints.

## Try it

Write a program that reads timestamped sensor samples, validates their shape, and logs processing time. Add a replay mode so you can reproduce a failure without hardware.
