# ROS 2 & Robot Software Architecture

## Overview

Build modular, observable robotics applications.

This topic guide identifies concepts to explore and an experiment to try. Use the linked documentation for implementation details.

## Prerequisites

[Robot Hardware & Embedded Systems](hardware.md)

## Key concepts

- Nodes, topics, services, actions, QoS.
- tf2.
- parameters and launch.
- URDF and joint states.
- rosbag2.
- diagnostics.
- perception-policy-control integration.

## Try it

Build a ROS 2 pipeline from sensors through inference to robot commands; record and replay operational traces; diagnose communication failures.

Record your setup, inputs, measurements, and failure cases. Keep the experiment small enough to repeat, and compare the result against a simple baseline.
