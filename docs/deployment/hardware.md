# Robot Hardware & Embedded Systems

## Overview

Practical interfaces between computation, sensors, actuators, and physical constraints.

This topic guide identifies concepts to explore and an experiment to try. Use the linked documentation for implementation details.

## Prerequisites

Basic programming familiarity and an interest in physical systems. Start with the [learning path](../start-here/learning-path.md) for context.

## Key concepts

- Microcontrollers and SBCs.
- servos/encoders.
- cameras, IMUs and force sensing.
- UART/I²C/SPI/CAN/Ethernet.
- timing and calibration.
- power, e-stop, and hardware limits.

## Try it

Read sensors and command actuators; diagnose timing and calibration problems; implement basic hardware safeguards.

Record your setup, inputs, measurements, and failure cases. Keep the experiment small enough to repeat, and compare the result against a simple baseline.
