# Synthetic Data & Scenario Engineering

## Overview

Create diverse simulation-based datasets and evaluation scenarios.

This topic guide identifies concepts to explore and an experiment to try. Use the linked documentation for implementation details.

## Prerequisites

[Computer Vision & Visual Perception](../foundations/computer-vision.md), [Isaac Sim & Digital Twin Engineering](isaac-sim.md)

## Key concepts

- Synthetic ground truth.
- rendering and annotation.
- lighting/object/camera variation.
- domain randomization.
- batch scenario execution.
- dataset quality.
- sim-to-real data gaps.

## Try it

Generate a labeled dataset; define scenario distributions; compare performance across synthetic and real observations.

Record your setup, inputs, measurements, and failure cases. Keep the experiment small enough to repeat, and compare the result against a simple baseline.
