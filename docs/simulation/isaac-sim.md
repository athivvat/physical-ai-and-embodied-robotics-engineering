# Isaac Sim & Digital Twin Engineering

## Overview

Create executable robot digital twins with virtual sensors and control interfaces.

This topic guide identifies concepts to explore and an experiment to try. Use the linked documentation for implementation details.

## Prerequisites

[OpenUSD & 3D Scene Composition](openusd.md), [Physics Simulation & Robot Modeling](physics.md)

## Key concepts

- Isaac Sim workflows.
- robot asset import.
- articulation setup.
- cameras/depth/LiDAR.
- scripting and headless automation.
- ROS 2 bridges.
- simulation tests and validation.

## Try it

Run repeatable manipulation scenarios; command a simulated arm; capture synchronized sensor and robot-state outputs.

Record your setup, inputs, measurements, and failure cases. Keep the experiment small enough to repeat, and compare the result against a simple baseline.
