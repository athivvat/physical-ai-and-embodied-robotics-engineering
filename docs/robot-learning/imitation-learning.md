# Imitation Learning & Robot Demonstrations

## Overview

Learn manipulation behavior from expert or teleoperated trajectories.

This topic guide identifies concepts to explore and an experiment to try. Use the linked documentation for implementation details.

## Prerequisites

[Deep Learning with PyTorch](../foundations/pytorch.md), [Computer Vision & Visual Perception](../foundations/computer-vision.md)

## Key concepts

- Behavior cloning.
- DAgger.
- offline distribution shift.
- teleoperation/leader–follower systems.
- episode segmentation.
- synchronized observation–action datasets.
- LeRobot workflows.
- demonstration quality.

## Try it

Collect and curate demonstrations; train a behavior-cloning policy; explain and measure failure from distribution shift.

Record your setup, inputs, measurements, and failure cases. Keep the experiment small enough to repeat, and compare the result against a simple baseline.
