# SO-101: Learning from Experience

**Project status:** Suggested project brief; implementation and results are not yet included.


**Goal:** Build a reproducible end-to-end system that learns tabletop pick-and-place behavior from demonstrations and/or simulation, then evaluates and executes a bounded task on physical hardware.

## Milestones

1. **M1 — Perception:** Calibrate a camera; identify objects and relevant scene geometry; measure detection and pose errors.
2. **M2 — Simulation:** Create an SO-101 digital twin and scripted manipulation scenarios; validate robot geometry and dynamics assumptions.
3. **M3 — Learning:** Collect episodes; train a policy; test unseen object placements and failure cases; optionally compare a predictive world model.
4. **M4 — Deployment:** Connect inference to the real arm; apply speed/workspace limits and supervised stops; record latency, success, interventions, and failures.
5. **M5 — Continuous learning:** Curate failed episodes; retrain or adapt; compare model versions against a fixed evaluation set.

## Artifacts to document

- Reproducible source code and environment setup
- Versioned datasets and episode schema
- OpenUSD simulation assets and task configuration
- Training checkpoints and evaluation scripts
- Hardware test protocol and safety checklist
- Results report covering accuracy, task success, latency, generalization, and observed failure modes


## Before hardware testing

Use suitable workspace controls, emergency stops, and supervision. Define motion limits and a staged test protocol before commanding the real arm.
